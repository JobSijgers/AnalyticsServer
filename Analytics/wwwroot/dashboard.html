Analytics Fetch Manager

Manage and create new fetch requests to Unity Analytics. Save configurations to JSON for use in AnalyticsService.cs.

Add New Fetch Request

Saved Fetch Requests

How to Use

  • Fill in the form to create a new fetch request configuration.
  • Click "Add Request" to add it to the list.
  • Use "Save to JSON" to download a file (e.g., fetchConfigs.json) that can be loaded into your AnalyticsService.cs (e.g., via Config.FetchRequests).
  • Use "Load from JSON" to import previously saved configurations.
  • Edit or delete requests from the list as needed.
